Проведи аудит БЕЗОПАСНОСТИ, ДОСТУПНОСТИ и UX проекта в рабочей директории: Neyroeros — 18+ галерея AI-арта (Next.js 16 App Router, Prisma 6.19 + SQLite, Sharp, деплой cPanel/Passenger, аутентификация Auth.js Credentials).

ВАЖНО: файлы НЕ меняй — только аудит и рекомендации. Ищи конкретику со ссылками файл:строка.

БЕЗОПАСНОСТЬ
1. Загрузка файлов (lib/storage/*, app/api/**/create|upload): проверка типа по сигнатуре vs по MIME от браузера, лимиты размера, path traversal, перезапись файлов.
2. Авторизация и разграничение ролей: где проверяется requireUser/requireAdmin, есть ли эндпоинты без проверки; может ли обычный пользователь менять чужие записи (сверь проверку authorId).
3. Проверки Origin/CSRF в POST-обработчиках — найди все, где такой проверки нет вообще.
4. Rate limit: где применяется и где его не хватает (регистрация, комментарии, лайки, загрузка).
5. SQL/инъекции или небезопасные raw-запросы; XSS через dangerouslySetInnerHTML.
6. Утечка приватных данных: не отдаются ли черновики, чужое авторство, чужие e-mail, внутренние ошибки в ответах.

ДОСТУПНОСТЬ
7. alt у изображений, aria-label у иконочных кнопок, семантика заголовков, контраст мелкого текста, доступность форм (label, автофокус, ошибки).

UX
8. Мобильная вёрстка, состояния загрузки, пустые состояния, поведение при ошибках, понятность действий.

В КОНЦЕ: раздел «Что делать первым» — 5 пунктов с наибольшим эффектом, по убыванию.

ФОРМАТ: markdown на русском. Каждый пункт: файл:строка → проблема → влияние (высокое/среднее/низкое) → действие. Без общих слов. Если проверку сделать нельзя — напиши «не проверено» и почему.
